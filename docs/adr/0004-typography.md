# Typography: Cormorant Garamond + DM Sans

Vinora uses **Cormorant Garamond** (serif) for display and wine identity moments, and **DM Sans** (sans-serif) for body copy, UI elements, labels, buttons, and navigation. This pairing balances elegance with readability, creating a premium yet accessible aesthetic appropriate for a Spanish wine marketplace.

**Considered Options:**
- **Option A: Crimson Pro + Inter** — Clean, modern, safe. Perhaps too generic/UI-focused.
- **Option B: Playfair Display + Source Sans 3** — High contrast, very editorial. Playfair felt too fashion/ornamental.
- **Option C: Cormorant Garamond + DM Sans** — Selected. Elegant serif with warmth, paired with a geometric sans that remains friendly.

**Decision Rationale:**
- Cormorant Garamond has Spanish heritage (Garamond origins connect to traditional European typography)
- The font's slightly more organic character suits wine's natural, agricultural product
- DM Sans geometric approach balances the organic serif with modern, app-like clarity
- The pairing works across all screen sizes and densities
- Differentiates from competitors (many use Inter/system fonts)

**Consequences:**
- All UI components use this single pairing — no font switching between views
- Typography scale must be disciplined (Cormorant has strong visual presence at large sizes)
- Font weights: 400, 500, 600, 700 for both families
- Load via Google Fonts CDN; fallback to system serif/sans if unavailable
