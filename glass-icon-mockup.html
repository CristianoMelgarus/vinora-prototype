8. Implementation Notes

  • SVG Path: Simple wine glass shape — bowl, stem, base. Can be swapped for more ornate design.
  • Fill Logic: Full = 100% opacity, Half = gradient or diagonal split, Empty = 20% opacity for visibility.
  • Colors: Primary (#722F37) for filled, border color (#E8E4DD) for empty. Supports dark mode via CSS variables.
  • Accessibility: Add aria-label="4.3 de 5 copas" for screen readers. Consider title attribute on hover.
  • Animation: Add fill animation on load — stroke-dashoffset transition from empty to filled state.
